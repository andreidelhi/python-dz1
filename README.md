# Аналитика каталога стримингового сервиса

Первая домашняя работа по Python. Программа анализирует каталог фильмов
процедурными функциями без pandas и других библиотек анализа данных.

## Требования

- Python 3.12 или новее;
- [uv](https://docs.astral.sh/uv/);
- Git (для истории разработки).

## Установка и запуск

```sh
uv sync --locked
uv run catalog_analysis.py
```

Проверка стиля:

```sh
uv run ruff check .
```

## Структура проекта

```text
python-dz1/
```

Внешних зависимостей для выполнения программы нет. Ruff установлен только

и не хранится в Git; `uv.lock` хранится в репозитории.

## Возможности

Функции проекта охватывают девять этапов задания:

1. Средний рейтинг, возраст фильмов и перевод длительности в часы и минуты.
2. Категории рейтингов через условия и метки периодов через `match`.
3. Обход каталога с `continue`, поиск через `while`, `break` и `else`.
4. Нормализация названий, создание slug и форматирование строк отчёта.
5. Сортировка фильмов по рейтингу и выборка топа без изменения каталога.
6. Статистика жанров, фильмография актёров и словарь оценок выше среднего.
7. Объединение и разность жанров, пересечение актёрских составов.
8. Ленивый генератор фильмов и суммирование длительности генераторным выражением.
9. Итоговый консольный отчёт.

Единая точка входа — `build_report(movies)` в блоке `if __name__ == "__main__":`.
При импорте модуля отчёт не печатается. Исходный каталог содержит десять фильмов;
его можно заменить списком словарей с теми же полями.

При обычном запуске также показаны демонстрации третьего этапа: список фильмов
вне жанра comedy через `for` и `continue`, поиск первого фильма с рейтингом выше
9.0 через `while` и `break`, а затем поиск в отфильтрованном каталоге, где
выполняется ветка `else` с сообщением «Шедевров не найдено».

Дополнительные функции можно вызывать после импорта, например:

```python
from catalog_analysis import above_average_ratings, movies, print_first_masterpiece

print(above_average_ratings(movies))
print_first_masterpiece([movie for movie in movies if movie["rating"] <= 9.0])
# Шедевров не найдено
```

Для пустого каталога `build_report` выводит «Каталог пуст.». Средний рейтинг
и возраст не определены для пустого списка: `average_rating` и `catalog_age_stats`
выбрасывают `ValueError`. Возраст по умолчанию рассчитывается относительно 2026 года;
у `catalog_age_stats` можно задать другой `current_year`.
